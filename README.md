# MarvelRivalsDB
SQL code to create tables of Marvel Rivals characters and team-ups. 


Tables constructed: 

**heroes**
| hero_id | name        | role       | hp   | difficulty | affiliation    |
|---------|-------------|------------|------|------------|----------------|
|         |             |            |      |            |                |

**team_ups**
| id | combo_name  | activator_id  | party1_id  | party2_id  |
|----|-------------|---------------|------------|------------|
|    |             |               |            |            |

Information sourced from [Marvel Rivals Wiki](https://marvelrivals.fandom.com/wiki/Heroes).
